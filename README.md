# Trabajo Práctico: Portada de Diario Responsiva

Este proyecto consiste en la creación de la portada de un diario digital ficticio llamado **"El Horizonte"**. El objetivo principal es aplicar conceptos de **Responsive Design** utilizando **Flexbox** y una estrategia **Mobile First**.

## Características del Proyecto
- **Diseño Original:** No se basa en ningún diario existente.
- **Mobile First:** El diseño fue pensado inicialmente para dispositivos móviles y se adapta a tablets y escritorios mediante Media Queries.
- **Flexbox:** Es la herramienta principal utilizada para el layout y la distribución de elementos.
- **CSS Modular:** Los estilos están separados en diferentes archivos (`normalize.css`, `styles.css`, `layout.css`, `typography.css`, `components.css`) para una mejor organización.
- **Accesibilidad y Semántica:** Uso de etiquetas HTML5 semánticas como `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>` y `<footer>`.
